# mern-backend-js

## Packages for CRUD Operations

### 1. Production Dependencies (`dependencies`)

- **[express](https://www.npmjs.com/package/express)**: Fast, unopinionated web framework for Node.js to handle routes and HTTP requests.
- **[mongoose](https://www.npmjs.com/package/mongoose)**: Elegant MongoDB object modeling for schema definition and CRUD database operations.
- **[dotenv](https://www.npmjs.com/package/dotenv)**: Loads environment variables from a `.env` file into `process.env`.
- **[cors](https://www.npmjs.com/package/cors)**: Middleware to enable Cross-Origin Resource Sharing for frontend-backend communication.
- **[morgan](https://www.npmjs.com/package/morgan)** (Optional): HTTP request logger middleware for debugging.

#### Installation:

```bash
npm install express mongoose dotenv cors morgan
```

---

### 2. Development Dependencies (`devDependencies`)

- **[nodemon](https://www.npmjs.com/package/nodemon)**: Automatically restarts the Node application when file changes in the directory are detected.

#### Installation:

```bash
npm install -D nodemon
```
